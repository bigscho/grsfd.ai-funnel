grsfd-core / design-system

Token and component reference for the coded grsfd core app. Not a mock — the product already exists; this page exists so it can pull from the same system as the rest of the brand surface.

NOTE

The core product is already built. This page exists so the coded app can reach for the same tokens, type, buttons, and chips as the rest of the brand surface — without a speculative dashboard muddying the review.

When the real UI needs a button, import from colors_and_type.css and match the styles below. When it needs a color, use the CSS variables — not raw hex.
