# grsfd.ai-funnel

The website and funnel pages for Grassfed (`grsfd.ai`).

## Structure

```
public/              Static site (served at the root domain)
  index.html         Home — Hero Prototype funnel (two agent cards → opt-in flows)
  pricing/index.html /pricing — marketing pricing page (React + Babel)
  unlock/            /unlock — grsfd opt-in flow
    index.html       opt-in form (MLS ID + contact)
    results/         post-submit results page
  farm/unlock/       /farm/unlock — grsfd-farm opt-in flow (Territory ZIP + contact)
  assets/            Logos
  *.jsx              React components (Babel-compiled in-browser, used on /pricing)
  colors_and_type.css
  icons.js

api/
  optin.js           POST /api/optin — writes leads to Airtable

brandkit/            Submodule: bigscho/grsfd-brandkit (Claude Design source of truth)
design-system/       Extracted brandkit zip (regenerated by sync script)
scripts/
  sync-design.sh     Regenerate public/ from the brandkit submodule
  build-home.py      Transform Hero Prototype.html -> public/index.html
  wire-optin.py      Patch opt-in forms to POST /api/optin
vercel.json          Clean URLs, no trailing slash
.env.example         Env var template
```

## Design sync workflow

**One-way: Claude Design → brandkit repo → this repo.** Never edit visuals here directly; the sync script will wipe them on the next pull.

When a new design export is pushed to `bigscho/grsfd-brandkit`:

```
git submodule update --remote brandkit
bash scripts/sync-design.sh
git add -A && git commit -m "sync: <note>" && git push
```

The sync re-extracts the zip into `design-system/`, copies CSS/logos/JSX into `public/`, rebuilds the home page from `Hero Prototype.html`, refreshes the opt-in flows, and re-applies the `/api/optin` form wiring (including the farm Territory-ZIP field). Idempotent.

## Deployment (Vercel)

1. Import the repo in Vercel → zero-config static + serverless functions.
2. Set these env vars in **Project → Settings → Environment Variables**:
   - `AIRTABLE_PAT`
   - `AIRTABLE_BASE_ID` = `appy3uDvQHssS7Cgi`
   - `AIRTABLE_TABLE_ID` = `tblfz6LtEDn5di2sG`
3. Add domain `grsfd.ai` in **Project → Settings → Domains**, follow the two DNS records Vercel shows, and add them at GoDaddy.

## Opt-in → Airtable mapping

Form submissions from `/unlock` and `/farm/unlock` POST to `/api/optin`, which writes a record to the Pipeline (All) table:

| Form field | Airtable field |
|---|---|
| First name | First Name |
| Last name | Last Name |
| (computed) | Agent Name (`First Last`) |
| Email | Email |
| Phone | Mobile Phone |
| MLS ID or Zip | Initial Response Text (`MLS ID: AR12345` or `Zip: 85251`) |
| — | Disposition = `NEW (<24hr)` (this is what the kanban groups on) |

## Local dev

Install the Vercel CLI and run `vercel dev` from the repo root. Copy `.env.example` to `.env.local` and fill in the real PAT.
